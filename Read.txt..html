5.2 STP Operations: Полное руководство для Read Aloud Тема 5.2 STP Operations в курсе CCNA2: SRWE подробно разбирает, как алгоритм Spanning Tree Algorithm (STA) превращает избыточную физическую топологию сети в логически беспетельную древовидную структуру. Процесс состоит из четырёх главных шагов, на каждом из которых коммутаторы обмениваются служебными кадрами — BPDU (Bridge Protocol Data Units). 1. Основы обмена и Bridge ID (BID) Для принятия всех решений коммутаторы используют Bridge ID (BID). BID — это 8-байтовое поле, которое состоит из трёх частей: Bridge Priority (Приоритет моста): 4 бита. Стандартное значение по умолчанию для всех коммутаторов Cisco составляет 32768. Диапазон — от 0 до 61440 с шагом 4096. Побеждает меньшее значение. Extended System ID (Расширенный идентификатор системы): 12 бит. Содержит номер VLAN (например, для VLAN 1 значение равно 1), что позволяет использовать разные корневые коммутаторы для разных сетей VLAN (технология PVST). MAC-адрес: 48 бит. Уникальный адрес коммутатора. Если приоритеты и расширенные ID равны, побеждает коммутатор с меньшим MAC-адресом (в шестнадцатеричном формате). 2. Четыре шага построения беспетельной топологии Шаг 1. Выбор корневого моста (Root Bridge) Цель: Выбрать центральную точку отсчёта для всех расчётов путей в сети. Как работает: Все коммутаторы начинают с того, каждые 2 секунды рассылают BPDU, заявляя себя корневыми мостами (их собственный BID совпадает с Root ID). Коммутатор с самым низким BID в конечном итоге признается всеми остальными в качестве Root Bridge. Важно: Если у всех коммутаторов заводской приоритет (32768 + номер VLAN), решающую роль играет MAC-адрес. Чтобы избежать случайного выбора слабого коммутатора, администратору рекомендуется вручную понижать приоритет ключевого устройства. Шаг 2. Определение стоимости пути (Root Path Cost) Путь к корневому мосту имеет общую стоимость (internal root path cost), которая складывается из стоимостей входящих портов всех сегментов на пути к корню. Стоимость портов зависит от пропускной способности (по стандарту IEEE 802.1D / short path cost): 10 Gbps = Cost 2 1 Gbps = Cost 4 100 Mbps = Cost 19 10 Mbps = Cost 100 Шаг 3. Выбор корневых портов (Root Ports, RP) Каждый некорневой коммутатор (non-root switch) должен выбрать ровно один корневой порт — это порт с наименьшей суммарной стоимостью пути до корневого моста. Шаг 4. Выбор назначенных портов (Designated Ports, DP) На каждом отдельном физическом сегменте между двумя коммутаторами выбирается один назначенный порт — у того коммутатора, чей путь к корню дешевле. Все порты корневого моста по определению являются назначенными портами (Designated Ports). Шаг 5. Выбор альтернативных / заблокированных портов (Alternate / Blocked Ports) Если порт не является ни корневым (RP), ни назначенным (DP), он переводится в статус Alternate (заблокированный). В этом состоянии порт не передает пользовательский трафик, разрывая потенциальную петлю уровня L2. 3. Разрешение тупиков при равной стоимости путей Если у коммутатора есть несколько одинаковых по стоимости путей к корню, алгоритм выбирает лучший порт по следующим критериям (в порядке приоритета): Lowest sender BID (наименьший BID соседнего передающего коммутатора). Lowest sender port priority (наименьший приоритет порта соседа). Lowest sender port ID (наименьший идентификатор порта соседа). 4. Таймеры и состояния портов STP Чтобы избежать временных петель при смене топологии, порты проходят через строгие временные интервалы и состояния: Основные таймеры: Hello Timer: интервал отправки BPDU (по умолчанию 2 секунды). Forward Delay Timer: время пребывания в состояниях Listening и Learning (по умолчанию 15 секунд). Max Age Timer: время ожидания BPDU перед началом изменения топологии (по умолчанию 20 секунд). Состояния портов: Disabled (Отключен): Порт административно выключен, в STP не участвует. Blocking (Блокировка): Начальное состояние. Кадры данных не передаются, BPDU принимаются. Максимальный возраст ожидания (Max Age) составляет 20 секунд. Listening (Прослушивание): Коммутатор принимает и отправляет BPDU, определяя структуру сети, но таблицы MAC-адресов не обновляет, данные не передает. Длительность равна Forward Delay (15 секунд). Learning (Обучение): Порт начинает изучать MAC-адреса устройств и наполнять таблицу коммутации, но пользовательские данные всё еще не пересылает (15 секунд). Forwarding (Пересылка): Порт полностью активен: передает данные пользователей, принимает и отправляет BPDU. 5. Особенности Per-VLAN Spanning Tree (PVST) Если в сети настроено несколько VLAN, классический STP (Common Spanning Tree) объединял их в одно дерево. Технология PVST (Per-VLAN Spanning Tree) запускает отдельный независимый экземпляр STP для каждого отдельного VLAN. Это позволяет распределять нагрузку: в одном VLAN корневым может быть один коммутатор, а в другом — совершенно другой.
