Модуль 15: Статическая маршрутизация Тема 15.2.1: IPv4 Next-Hop Static Route (Статический маршрут IPv4 до следующего перехода) 1. Суть и определение В сетевой академии Cisco изучение статической маршрутизации начинается с настройки стандартных маршрутов. Первый и самый популярный вариант — это статический маршрут до следующего перехода (Next-Hop Static Route). Его главная особенность заключается в следующем: В команде конфигурации указывается только IP-адрес следующего маршрутизатора (next-hop), через который пойдет трафик. Сам исходящий интерфейс маршрутизатора явно не прописывается — устройство автоматически вычисляет его на основе таблицы маршрутизации, сопоставляя IP адрес следующего перехода с уже известными подключенными сетями. 2. Пример топологии из курса В учебном материале рассматривается топология из трех соединенных последовательно роутеров: R1 находится в левой части сети. R2 расположен посередине и выполняет роль промежуточного узла. R3 находится на правой стороне. Между устройствами настроены следующие подсети: Локальная сеть роутера R1: 172.16.3.0/24. Канал связи (WAN) между R1 и R2: 172.16.2.0/24. Локальная сеть роутера R2: 172.16.1.0/24. Канал связи (WAN) между R2 и R3: 192.168.1.0/24. Локальная сеть роутера R3: 192.168.2.0/24. 3. Синтаксис и команды настройки для R1 Чтобы роутер R1 «знал», как добираться до трех удаленных сетей, к которым он не подключен напрямую, администратор настраивает статические маршруты. Общий формат команды на интерфейсе командной строки (CLI):ip route [Целевая_сеть] [Маска_подсети] [IP_адрес_следующего_перехода] Для роутера R1 прописываются три команды, где в качестве шлюза для всех трех направлений выступает IP-адрес соседнего маршрутизатора R2 (172.16.2.2): Маршрут до локальной сети R2:R1(config)# ip route 172.16.1.0 255.255.255.0 172.16.2.2 Маршрут до канала связи между R2 и R3:R1(config)# ip route 192.168.1.0 255.255.255.0 172.16.2.2 Маршрут до удаленной локальной сети R3:R1(config)# ip route 192.168.2.0 255.255.255.0 172.16.2.2 4. Проверка результата (Анализ таблицы маршрутизации) После ввода команд проверить корректность настройки можно с помощью команды просмотра таблицы маршрутизации. В учебнике приводится пример вывода: R1# show ip route | begin Gateway В результате мы видим таблицу, где напротив добавленных сетей стоит буква S (Static): S 172.16.1.0/24 [1/0] via 172.16.2.2 S 192.168.1.0/24 [1/0] via 172.16.2.2 S 192.168.2.0/24 [1/0] via 172.16.2.2 Что означают эти параметры: Буква S означает, что маршрут добавлен вручную (статически). Значение [1/0] в квадратных скобках — это административное расстояние (Administrative Distance, равное 1 для статических маршрутов) и метрика (стоимость). Конструкция via 172.16.2.2 указывает IP-адрес следующего прыжка (next-hop), куда роутер будет пересылать пакеты, адресованные в соответствующие сети.
