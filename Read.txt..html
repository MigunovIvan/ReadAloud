Синтаксис команды: tar пробел минус c пробел в квадратных скобках минус f пробел АРХИВ пробел в квадратных скобках ОПЦИИ пробел в квадратных скобках ФАЙЛ с многоточием. Для создания архива с помощью команды tar требуются две именованные опции: Опция минус c — создать архив. Опция минус f АРХИВ — использовать файл архива. Аргумент АРХИВ будет именем создаваемого файла архива. Все остальные аргументы рассматриваются как имена входных файлов — это может быть шаблон подстановки, список файлов или и то и другое вместе. Следующий пример показывает создание tar-файла, который также называют тарболлом, из нескольких файлов. Первый аргумент создаёт архив с именем alpha_files.tar. Шаблон подстановки звёздочка используется, чтобы включить в архив все файлы, которые начинаются на alpha: Пользователь sysadmin на хосте localhost в каталоге тильда косая черта Documents, приглашение командной строки: tar пробел минус cf пробел alpha_files.tar пробел alpha звёздочка. Затем проверяем размер файла: sysadmin на хосте localhost в каталоге тильда косая черта Documents: ls пробел минус l пробел alpha_files.tar. Вывод: права минус rw-rw-r--, счётчик ссылок один, владелец sysadmin, группа sysadmin, размер десять тысяч двести сорок байт, дата тридцать первое октября семнадцать ноль семь, имя alpha_files.tar. Итоговый размер alpha_files.tar составляет десять тысяч двести сорок байт. Обычно тарболлы немного больше суммарного размера исходных файлов из-за служебной информации, необходимой для воссоздания исходных файлов. Тарболлы можно сжимать для более удобной передачи — либо с помощью утилиты gzip поверх архива, либо попросив саму утилиту tar сделать это с помощью опции минус z. Опция минус z — сжать или распаковать архив с помощью команды gzip. Следующий пример показывает ту же команду, что и в предыдущем примере, но с добавлением опции минус z: sysadmin на хосте localhost в каталоге тильда косая черта Documents: tar пробел минус czf пробел alpha_files.tar.gz пробел alpha звёздочка. Проверяем размер: sysadmin на хосте localhost в каталоге тильда косая черта Documents: ls пробел минус l пробел alpha_files.tar.gz. Вывод: права минус rw-rw-r--, счётчик ссылок один, владелец sysadmin, группа sysadmin, размер четыреста семнадцать байт, дата тридцать первое октября семнадцать пятнадцать, имя alpha_files.tar.gz. Результат намного меньше самого тарболла, и полученный файл совместим с gzip, которую можно использовать для просмотра сведений о сжатии. Несжатый размер такой же, как если бы вы заархивировали данные отдельным шагом: sysadmin на хосте localhost в каталоге тильда косая черта Documents: gzip пробел минус l пробел alpha_files.tar.gz. Вывод таблицы: сжатый размер — четыреста семнадцать, несжатый размер — десять тысяч двести сорок, степень сжатия — девяносто шесть целых одна десятая процента, имя несжатого файла — alpha_files.tar. Хотя расширения файлов не влияют на то, как система обрабатывает файл, общепринятое соглашение — использовать расширение точка tar для тарболлов, а точка tar точка gz или точка tgz для сжатых тарболлов. Вместо gzip можно использовать сжатие bzip2, заменив опцию минус z на опцию минус j и используя расширение точка tar точка bz2, точка tbz или точка tbz2. Опция минус j — сжать или распаковать архив с помощью команды bzip2. Например, чтобы заархивировать и сжать каталог School: sysadmin на хосте localhost в каталоге тильда косая черта Documents: tar пробел минус cjf пробел folders.tbz пробел School.
