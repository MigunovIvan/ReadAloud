Раздел 4.5.3. Что я узнал в этом модуле? Часть первая. Операция маршрутизации между VLAN. Хосты, находящиеся в одной VLAN, не могут взаимодействовать с хостами в другой VLAN без использования маршрутизатора или коммутатора третьего уровня, которые обеспечивают маршрутизацию. Межсетевая маршрутизация между VLAN — это процесс пересылки сетевого трафика из одной VLAN в другую. Существует три основных варианта реализации этой маршрутизации: Устаревший способ. Маршрутизатор на одном устройстве (Router-on-a-Stick). Коммутатор третьего уровня с использованием SVI. В устаревшем варианте использовался маршрутизатор с несколькими физическими интерфейсами Ethernet. Каждый интерфейс маршрутизатора подключался к порту коммутатора в соответствующей VLAN. Однако требование иметь отдельный физический интерфейс на каждую VLAN быстро исчерпывает физические ресурсы и пропускную способность маршрутизатора. Метод «маршрутизатор на одном устройстве» (Router-on-a-Stick) требует наличия всего одного физического интерфейса Ethernet для маршрутизации трафика между несколькими VLAN. В этом случае физический интерфейс маршрутизатора Cisco IOS настраивается как транк 802.1Q и подключается к транковому порту коммутатора второго уровня. Сам интерфейс маршрутизатора разделяется на субинтерфейсы для идентификации каждой маршрутизируемой VLAN. Настроенные субинтерфейсы представляют собой программно определяемые виртуальные интерфейсы, связанные с единым физическим интерфейсом Ethernet. Современный метод — это межсетевая маршрутизация на коммутаторе третьего уровня с использованием виртуальных интерфейсов коммутатора (SVI). Интерфейс SVI создается для конкретной VLAN, существующей на коммутаторе. SVI выполняет для VLAN те же функции, что и физический интерфейс маршрутизатора: он обеспечивает обработку пакетов третьего уровня, отправляемых на все порты коммутатора, связанные с данной VLAN, или получаемых от них. Часть вторая. Маршрутизация между VLAN с использованием Router-on-a-Stick. Чтобы настроить коммутатор для работы с VLAN и транкингом, выполняются следующие шаги: Создание и наименование VLAN; Создание интерфейса управления; Настройка портов доступа (access-портов); Настройка транковых портов. Метод «маршрутизатор на одном устройстве» требует создания отдельного субинтерфейса для каждого маршрутизируемого VLAN. Субинтерфейс создается в глобальном режиме конфигурации с помощью команды interface с указанием идентификатора интерфейса и номера субинтерфейса через точку. Каждому субинтерфейсу маршрутизатора должен быть назначен IP-адрес из уникальной подсети для обеспечения маршрутизации. После завершения настройки всех субинтерфейсов физический интерфейс необходимо активировать командой no shutdown. Для проверки сетевого взаимодействия с хоста выполняется команда ping до узла в другой VLAN. Также команда ping применяется для проверки связи с коммутатором и маршрутизатором. Для проверки состояния и устранения неполадок используются команды: show ip route — просмотр таблицы маршрутизации; show ip interface brief — краткий статус интерфейсов; show interfaces — подробный статус и параметры интерфейсов; show interfaces trunk — проверка состояния транковых каналов. Часть третья. Маршрутизация между VLAN с использованием коммутаторов уровня 3. В корпоративных локальных сетях масштаба кампуса для межсетевой маршрутизации используются коммутаторы третьего уровня. Они используют аппаратную коммутацию, что обеспечивает более высокую скорость обработки пакетов по сравнению со обычными маршрутизаторами. Возможности коммутатора третьего уровня включают: Маршрутизацию из одной VLAN в другую с использованием нескольких виртуальных интерфейсов (SVI); Преобразование порта коммутатора второго уровня в интерфейс третьего уровня — так называемый «маршрутизируемый порт». Для организации маршрутизации между VLAN коммутатор уровня 3 использует SVI. Они настраиваются с помощью команды interface vlan с указанием номера VLAN — точно так же, как создается управляющий SVI на коммутаторе уровня 2. Для каждой маршрутизируемой VLAN необходимо создать свой SVI уровня 3. Порядок настройки включает: Создание VLAN; Создание интерфейсов SVI для этих VLAN; Настройку портов доступа; Включение IP-маршрутизации командой ip routing. Для проверки доступности хоста в другой VLAN используется команда ping. Чтобы объявлять VLAN в сети, применяется статическая или динамическая маршрутизация. Чтобы настроить маршрутизируемый порт (L3-порт) на коммутаторе уровня 3, необходимо отключить функцию переключения уровня 2 на конкретном порту с помощью команды no switchport. Этот интерфейс настраивается с IP-адресом для подключения к маршрутизатору или другому коммутатору уровня 3. Для связи коммутатора уровня 3 с маршрутизатором выполняются следующие шаги: Настройка маршрутизируемого порта; Включение маршрутизации; Настройка протокола или статических маршрутов; Проверка таблицы маршрутизации и сквозного сетевого подключения. Часть четвертая. Устранение неполадок маршрутизации между VLAN. Неполадки в межсетевой маршрутизации обычно связаны со следующими проблемами: Отсутствие или удаление VLAN; Проблемы с транковыми портами коммутатора; Неправильная настройка портов доступа; Ошибки в конфигурации маршрутизатора. VLAN может отсутствовать, если она не была создана, была случайно удалена или не разрешена в списке допустимых VLAN на транковом канале. В устаревшем варианте маршрутизации частая ошибка — подключение интерфейса маршрутизатора к порту коммутатора, назначенному не в ту VLAN. В методе «маршрутизатор на одном устройстве» наиболее распространенной причиной ошибок является неправильная настройка транкового порта. Если есть подозрение на проблему в конфигурации порта доступа, используйте команду ping и команду show interfaces [id] switchport для проверки назначения VLAN на порту. Ошибки на маршрутизаторе в режиме Router-on-a-Stick чаще всего связаны с неверной привязкой VLAN к субинтерфейсу или ошибками в IP-адресации. Проверить текущий статус и IP-адреса субинтерфейсов можно с помощью команды show ip interface brief.
