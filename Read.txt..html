Раздел 5.5.4. Функции (Functions) Что такое функции и зачем они нужны? Подобно алиасам, функции позволяют создавать собственные команды на основе уже существующих или даже переопределять встроенные команды оболочки и утилиты. Однако функции устроены сложнее и обычно применяются в сценариях (скриптах) командной строки Bash. Главное отличие функции от алиаса заключается в том, что функция способна выполнять несколько команд последовательно, избавляя вас от необходимости вводить их вручную снова и снова. Синтаксис создания функции Чтобы создать функцию в терминале, используется следующий формат: Bash имя_функции () { команды } Обратите внимание на важные детали синтаксиса: Название функции (function_name) может быть абсолютно любым на усмотрение администратора. Обязательно наличие круглых скобок () сразу после имени. Тело функции заключается в фигурные скобки { }. Внутри фигурных скобок команды обычно записываются с отступами (табуляцией) для лучшей читаемости. Практический пример создания функции В учебном материале приводится пример создания функции с именем my_report. Она объединяет три разные команды: вывод содержимого папки Documents, текущую дату и текстовое сообщение. При вводе этой функции в терминале сессия выглядит следующим образом: Bash sysadmin@localhost:~$ my_report () { > ls Documents > date > echo "Document directory report" > } Обратите внимание на поведение интерфейса: когда вы открываете фигурную скобку { и нажимаете ввод, приглашение командной строки меняется с привычного значка доллара на символ >. Это указывает на то, что оболочка ждет ввода команд внутри функции. Как только вы закроете функцию закрывающей фигурной скобкой }, ввод команд завершится. Вызов созданной функции После того как функция успешно создана, вы можете вызывать её точно так же, как и любую стандартную команду Linux, просто набрав её имя в командной строке:sysadmin@localhost:~$ my_report В результате последовательно выполнятся все заложенные в неё инструкции: на экран выведется список файлов в папке Documents, отобразится текущая системная дата и время (например, Wed Oct 13 06:54:04 UTC 2021), а также строка отчета Document directory report.
