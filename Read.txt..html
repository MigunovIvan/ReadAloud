Для просмотра документации в формате info для конкретной команды используется простая команда: info с указанием имени нужной программы, например: info ls. Внутренне документ info разбит на отдельные структурные блоки, которые называются узлами (nodes). В верхней строке интерфейса всегда отображается служебная информация о текущем местоположении. Например, текст вида Next: dir invocation, Up: Directory listing показывает, куда можно перейти дальше или подняться на уровень выше. В самом центре экрана выводится текст справки, а внизу находится строка состояния, которая подсказывает текущую версию info и общие подсказки (например, нажать клавишу H для справки или h для краткого руководства). Один из важнейших элементов структуры info — встроенное меню, которое обозначается строкой * Menu:. Под ним располагаются гиперссылки на подразделы, описывающие различные аспекты работы команды, например: Which files are listed:: What information is listed:: Sorting the output:: Чтобы открыть нужный подраздел, достаточно переместить на него курсор с помощью стрелок на клавиатуре и нажать клавишу Enter. При этом документ откроется в виде дочернего узла. Для навигации по иерархии документа предусмотрены специальные клавиши: Клавиша U (Up) поднимает на один уровень вверх к началу родительского узла. Клавиша L (Last) возвращает ровно в то место, откуда вы перешли по ссылке, что очень удобно для возврата к прерванному чтению после изучения подраздела.
