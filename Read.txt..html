Тема 12.7.6: Методы шифрования беспроводных сетей Введение Шифрование используется для защиты передаваемых данных. Если злоумышленник перехватит зашифрованный трафик, он не сможет расшифровать его за разумное время. Стандарты безопасности беспроводных сетей WPA и WPA2 используют для этого два основных протокола шифрования: TKIP и AES. 1. Протокол TKIP (Temporal Key Integrity Protocol) Где применяется: Является методом шифрования, который используется в стандарте WPA. Назначение: Был создан для поддержки уставшего и старого оборудования беспроводных сетей путем устранения фундаментальных уязвимостей оригинального метода шифрования WEP из стандарта 802.11. Принцип работы: TKIP использует базовые механизмы WEP, но дополнительно шифрует полезную нагрузку на Канальном уровне (Layer 2) с помощью собственного алгоритма. Главная особенность: протокол выполняет проверку целостности сообщения — Message Integrity Check (MIC) в зашифрованном пакете. Это позволяет гарантировать, что передаваемое сообщение не было изменено или подменено злоумышленником в процессе передачи. 2. Протокол AES (Advanced Encryption Standard) Где применяется: Является методом шифрования, используемым в более современном стандарте WPA2. Почему он предпочтителен: Это значительно более мощный и надежный метод шифрования по сравнению с TKIP. Техническая основа: Протокол AES использует режим шифрования CCMP (Counter Cipher Mode with Block Chaining Message Authentication Code Protocol). Что делает CCMP: Этот механизм позволяет принимающим хостам (устройствам-получателям) точно распознавать, были ли изменены зашифрованные или незашифрованные биты данных во время пересылки в эфире.
