3.5 Языки разработки и программирования Поддержка разработки в Linux Среда для разработчиков: Поскольку Linux создавался программистами и развивается за счет их вклада, в системе заложена великолепная поддержка разработки ПО. Инструменты на борту: Каждая система оснащена мощными текстовыми редакторами, программируемыми командными оболочками и огромным количеством встроенных утилит. Компилируемые и интерпретируемые языки Языки программирования позволяют писать инструкции на понятном человеку языке, а затем переводить их в машинный код, понятный процессору. Они делятся на две категории: Компилируемые языки: Исходный код переводится в машинный код целиком перед запуском программы. Пример (C): Сама операционная система Linux написана на языке C. Главный плюс Си — он очень близко «общается» с железом, позволяя создавать максимально компактные и быстрые программы. Развитие Си: Позже появились C++ (с поддержкой объектно-ориентированного подхода) и Objective C, который активно используется в продуктах Apple. Интерпретируемые языки: Код переводится в машинный язык прямо во время выполнения программы («на лету»). Хотя это требует дополнительных ресурсов процессора, программист экономит массу времени, так как ему не нужно постоянно ждать компиляции. Особенности языка Java и виртуальная машина Промежуточный подход: Язык Java устроен иначе. Он компилирует код не в машинный язык конкретного процессора, а в специальный универсальный формат — байт-код. JVM: Этот байт-код запускается внутри специальной программы на компьютере пользователя — виртуальной машины Java (JVM). Главный плюс: Написанная одинжды программа на Java будет работать на любом устройстве, где установлена JVM — от мощного сервера до умного телевизора. Кроме того, виртуальная машина сама управляет распределением оперативной памяти для программ. Популярные интерпретируемые языки JavaScript: Высокоуровневый язык для создания интерактивных элементов на веб-страницах и работы в интернете. Не путайте его с Java — это совершенно разные языки. Perl: Исторически создавался для удобной работы с текстом. До сих пор любим системными администраторами за автоматизацию задач и написание сценариев. PHP: Язык, созданный специально для динамических сайтов. Код PHP обрабатывается веб-сервером на лету перед отправкой в браузер. На нем написаны такие популярные платформы, как WordPress и части социальной сети Facebook. Ruby: Язык, который делает сложные задачи простыми. Благодаря каркасу Ruby on Rails он популярен для создания веб-приложений, а также используется в мощных системах автоматизации и управления серверами, таких как Chef и Puppet. Python: Один из самых универсальных и популярных языков общего назначения. Благодаря простоте синтаксиса и мощным инструментам вроде Django, он стал фаворитом в научных кругах и веб-разработке. Библиотеки и готовые инструменты Что такое библиотека: Это готовый набор программных модулей, который избавляет разработчика от необходимости писать типовые задачи с нуля. ImageMagick: Библиотека и набор командных утилит для работы и обработки изображений прямо из терминала. OpenSSL: Стандартная криптографическая библиотека для обеспечения безопасности и шифрования данных. Системная библиотека C: Базовый набор функций, к которому обращаются программы и другие языки для чтения файлов и вывода информации на экран.
