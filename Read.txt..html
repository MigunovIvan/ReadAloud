11.2.2: Шаги по защите от атак типа VLAN Hopping Чтобы полностью закрыть уязвимости, которыми пользуются хакеры при атаках на VLAN, сетевым инженерам необходимо выполнить 5 ключевых шагов настройки коммутатора: Шаг 1. Отключение автоматического согласования (DTP) на портах доступа Команда: switchport mode access Смысл: Принудительно переводит обычные порты подключения конечных устройств (компьютеров, принтеров) в режим доступа. Это полностью блокирует отправку DTP-сообщений и не дает злоумышленнику перевести порт в транковый режим. Шаг 2. Отключение неиспользуемых портов Команды: switchport mode access, switchport access vlan <номер>, shutdown Смысл: Все свободные физические порты коммутатора нужно заблокировать (команда shutdown) и перенести в отдельную резервную «черную» VLAN (например, VLAN 1000). Это защитит сеть от физического подключения чужих устройств. Шаг 3. Ручное включение транковых соединений Команда: switchport mode trunk Смысл: Настоящие порты между коммутаторами настраиваются вручную именно как транковые, исключая любые двусмысленности в их работе. Шаг 4. Отключение DTP на транковых портах Команда: switchport nonegotiate Смысл: Полностью отключает протокол DTP на линиях связи между коммутаторами. Порт больше не ведет переговоры о транке с неизвестными устройствами — он работает как транк принудительно. Шаг 5. Изменение нативной VLAN Команда: switchport trunk native vlan <номер> Смысл: Перенос служебного нетегированного трафика (Native VLAN) со стандартной первой сети (VLAN 1) на любую другую неиспользуемую сеть (например, VLAN 999). Это предотвращает атаки двойной инкапсуляции (Double-Tagging). Практический пример настройки на коммутаторе (на примере Cisco IOS) Рассмотрим, как это выглядит в реальной конфигурации интерфейсов: Для активных портов доступа (порты с 1 по 16): Мы переводим их в режим доступа, чтобы отключить любые транки: interface range fa0/1 - 16 switchport mode access Для неиспользуемых портов (порты с 17 по 20): Мы переводим их в режим доступа, отправляем в изолированную VLAN 1000 и отключаем: interface range fa0/17 - 20 switchport mode access switchport access vlan 1000 shutdown Для транковых портов (порты с 21 по 24): Мы настраиваем их вручную как транки, отключаем DTP и меняем нативную VLAN на 999: interface range fa0/21 - 24 switchport mode trunk switchport nonegotiate switchport trunk native vlan 999
