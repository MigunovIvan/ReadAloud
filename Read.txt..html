Разбираем модуль 11.5: Защита от атак на протокол связующего дерева (Mitigate STP Attacks), который идеально подходит для прослушивания через Read Aloud. 11.5. Защита от атак на STP (Spanning Tree Protocol) Злоумышленники могут манипулировать протоколом STP, чтобы перехватить роль корневого моста (Root Bridge) и полностью изменить топологию сети. Для защиты от таких атак используются две ключевые функции: PortFast и BPDU Guard. 1. PortFast (Ускорение портов доступа) Зачем нужен: Обычный порт коммутатора при подключении проходит через медленные состояния listening (прослушивание) и learning (обучение), ожидая сходимости STP. PortFast мгновенно переводит порт из блокирующего состояния в состояние передачи (forwarding). Где применять: Исключительно на портах доступа (access ports), к которым подключены конечные устройства (персональные компьютеры, принтеры). Риск: Если включить PortFast на порте, соединенном с другим коммутатором или хабом, можно случайно создать петлю маршрутизации (bridging loop). 2. BPDU Guard (Защита от BPDU-сообщений) Зачем нужен: Даже при включенном PortFast порт продолжает слушать служебные сообщения STP — BPDU (Bridge Protocol Data Unit). Если на такой порт прилетит неожиданный BPDU (например, от неавторизованного коммутатора, подключенного злоумышленником), функция BPDU Guard немедленно переводит порт в безопасный режим err-disabled (порт физически отключается). Восстановление: После срабатывания защиты порт нужно либо включать вручную, либо настроить автоматическое восстановление командой errdisable recovery cause bpduguard. Правило безопасности: Всегда включайте BPDU Guard на всех портах, где активирован PortFast. 3. Настройка PortFast и BPDU Guard (Команды Cisco IOS) Настроить эти функции можно точечно на интерфейсе или глобально сразу для всех портов доступа: Включение PortFast и BPDU Guard по умолчанию для всех портов доступа: Plaintext S1(config)# spanning-tree portfast default S1(config)# spanning-tree portfast bpduguard default (Команда глобально включает PortFast и BPDU Guard на всех интерфейсах, настроенных в режиме доступа). Ручная настройка диапазона портов (как на практике в лабораторной работе): Plaintext S1(config)# interface range fa0/1 - 24 S1(config-if-range)# switchport mode access S1(config-if-range)# exit S1(config)# spanning-tree portfast default S1(config)# spanning-tree portfast bpduguard default 4. Проверка корректности настройки Чтобы убедиться, что функции активны по умолчанию, используется команда просмотра сводной информации STP: Plaintext S1# show spanning-tree summary В выводе команды должны быть строки: Portfast Default is enabled PortFast BPDU Guard Default is enabled
