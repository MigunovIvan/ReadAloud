Разбор темы 5.4.3 Path Variable (Переменная PATH) для вставки в Read Aloud: Что такое PATH: Это одна из важнейших переменных окружения в Bash. Она хранит упорядоченный список каталогов (папок), в которых оболочка ищет исполняемые файлы при вводе любой команды. Откуда берётся ошибка команд: Если вы вводите корректную команду, но терминал выдаёт сообщение command not found, это значит, что оболочка проверила все папки из переменной PATH, но не нашла там программу с таким именем. Как посмотреть текущий путь: Команда echo $PATH выводит список всех каталогов, разделённых двоеточием (:). Оболочка проверяет их строго по порядку слева направо. Пример стандартного вывода: /home/sysadmin/bin:/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin:/usr/games Понятие «пути» (Path): Путь — это список каталогов, разделенных символом косой черты (/), который служит «адресом» для поиска файлов в файловой системе (например, /home/sysadmin — это путь к домашнему каталогу). Если команда не найдена ни в одной из директорий списка, система возвращает ошибку (например, при вводе несуществующей команды zed появится сообщение -bash: zed: command not found). Как изменить и дополнить переменную PATH: Если на компьютере устанавливается пользовательское ПО в нестандартную папку, переменную PATH можно расширить, добавив в неё новый путь. Пример добавления папки /usr/bin/custom:PATH=/usr/bin/custom:$PATH Важное правило при обновлении: При изменении переменной PATH обязательно нужно добавлять текущее значение $PATH в конец выражения (через двоеточие). Если этого не сделать, вы перезапишете переменную и полностью потеряете доступ к стандартным системным командам.
