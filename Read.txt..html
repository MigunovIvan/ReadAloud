8.4.1 Переименование файлов. Команда mv используется не только для перемещения файла, но и для его переименования. Если местом назначения для команды mv указан каталог, файл перемещается в этот каталог. Имя файла меняется только в том случае, если также указано новое имя файла назначения. В примере в терминале пользователь sysadmin на хосте localhost в домашнем каталоге тильда выполняет команду: ls. Выводятся элементы: Desktop, Downloads, Pictures, Templates, example.txt, Documents, Music, Public, Videos, hosts.copy. Далее выполняется команда: mv example.txt Videos/newexample.txt. Снова выполняется команда: ls. Теперь в списке есть Desktop, Downloads, Pictures, Templates, hosts.copy, Documents, Music, Public, Videos. Файл example.txt переместился из текущего каталога. Выполняется команда: ls Videos. Внутри каталога Videos находятся два файла: hosts и newexample.txt. Если каталог назначения не указан, файл переименовывается с использованием указанного имени файла назначения и остается в исходном каталоге. Например, следующие команды переименовывают файл newexample.txt в myfile.txt. Пользователь переходит в каталог командой: cd Videos. Приглашение командной строки теперь показывает каталог тильда косая черта Videos. Выполняется команда: ls. Выводятся два файла: hosts и newexample.txt. Выполняется команда: mv newexample.txt myfile.txt. Снова выполняется команда: ls. Теперь выводятся файлы: hosts и myfile.txt. Подумайте об этом примере с командой mv так: переместить файл newexample.txt из текущего каталога в этот же текущий каталог и дать новому файлу имя myfile.txt.
