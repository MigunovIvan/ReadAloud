До сих пор мы рассматривали man-страницы только для обычных команд. Однако в системе есть множество других компонентов, требующих документации: это системные и административные команды, конфигурационные файлы, различные библиотеки и компоненты ядра. В результате в любом дистрибутиве Linux содержатся тысячи страниц руководства. Чтобы в них не запутаться, все man-страницы разбиты на девять основных разделов: General Commands — общие команды для пользователей. System Calls — системные вызовы, доступные из программ. Library Calls — функции программирования и библиотечные вызовы. Special Files — специальные файлы, обычно находящиеся в каталоге dev. File Formats and Conventions — форматы файлов и стандарты конфигураций. Games — игры и развлекательные программы. Miscellaneous — разная информация и утилиты. System Administration Commands — команды системного администрирования, предназначенные для суперпользователя root. Kernel Routines — внутренние процедуры ядра Linux. Как работает поиск по разделам Когда вы вводите команду вроде man cal, программа man начинает последовательно просматривать эти разделы по порядку от первого до последнего, пока не найдет первое совпадение. Если запрашиваемая страница не найдена ни в одном из разделов, вы увидите сообщение об ошибке, например: No manual entry for zed. Чтобы узнать, к какому именно разделу принадлежит конкретная man-страница, достаточно посмотреть на номер в скобках на первой строке её заголовка. Например, запись CAL(1) означает, что команда cal относится к первому разделу. Работа с одинаковыми именами в разных разделах Иногда разные сущности в системе могут называться абсолютно одинаково. Классический пример — слово passwd. Под этим именем существует и пользовательская команда для смены пароля, и важный системный файл, в котором хранятся данные учетных записей. Команда passwd относится к первому разделу (USER COMMANDS). Если вы просто введете man passwd, система по умолчанию откроет именно её. Файл passwd описывается в пятом разделе (File Formats and Conventions). Чтобы принудительно открыть man-страницу из конкретного раздела, нужно указать номер раздела перед именем команды. Например, чтобы открыть справку по файлу конфигурации, вводится:man 5 passwd Поиск страниц по имени и ключевым словам Не всегда удается вспомнить точное название нужной man-страницы. В таких случаях помогают специальные ключи команды man: Ключ -f ищет точное или частичное совпадение по имени и выдает список всех подходящих страниц с указанием их номеров и краткого описания. Например, команда man -f passwd покажет и саму утилиту смены пароля из первого раздела, и файл настроек из пятого, и команду вычисления хэшей из раздела ssl. Примечание: во многих дистрибутивах Linux аналогичным образом работает отдельная команда whatis. Ключ -k выполняет поиск ключевого слова не только по названиям, но и по кратким описаниям всех man-страниц в системе. Например, поиск по запросу man -k copy выдаст длинный список команд, так или иначе связанных с копированием (таких как cp, dd, install или scp). Примечание: на большинстве систем эту же задачу выполняет команда apropos. Поскольку страниц руководства тысячи, при использовании ключевых слов старайтесь быть как можно точнее. Запросы вроде обычных предлогов или слов вроде "the" выдадут тысячи бесполезных результатов.
