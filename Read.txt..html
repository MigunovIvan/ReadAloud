Тема 13.3.11: Настройка WPA2 Enterprise WLAN (Configure a WPA2 Enterprise WLAN) В этой теме мы объединяем все предыдущие шаги и создаем саму беспроводную сеть (WLAN), защищенную протоколом WPA2 Enterprise с использованием внешнего сервера аутентификации RADIUS (например, сервера AAA/ISE). Для успешной настройки WLAN выполните следующие шаги: Шаг 1. Переход к созданию нового WLAN Где искать в меню: В верхнем меню графического интерфейса WLC перейдите на вкладку WLANs, а затем в правом верхнем углу выберите из выпадающего списка пункт Create New (Создать новый) и нажмите кнопку Go. Что делает этот шаг: Открывает мастер создания новой беспроводной сети. Шаг 2. Основные параметры сети (Profile Name и SSID) Что нужно указать: Profile Name (Имя профиля) — внутреннее имя для идентификации сети на контроллере (например, Corporate-WLAN). SSID — имя беспроводной сети, которое пользователи видят на своих устройствах (например, CorpNet). ID — порядковый номер WLAN, который назначается автоматически. Что делает этот шаг: Задает название сети и то, как она будет отображаться для беспроводных клиентов. Шаг 3. Привязка интерфейса (Interface Mapping) Что нужно указать: В поле Interface / VLAN mapping выберите созданный ранее виртуальный интерфейс (например, vlan5), который мы настроили в теме 13.3.7. Что делает этот шаг: Связывает создаваемую беспроводную сеть с конкретным сетевым сегментом и подсетью, обеспечивая правильную маршрутизацию трафика. Шаг 4. Настройка безопасности WPA2 Enterprise (Security) Где искать: Перейдите на вкладку Security (Безопасность) вверху формы настройки WLAN, а затем выберите подвкладку Layer 2 (Уровень 2). Что нужно указать: В поле Layer 2 Security выберите значение WPA+WPA2. В блоке WPA2 Policy поставьте галочку напротив WPA2 (убедитесь, что выбран алгоритм шифрования AES). Что делает этот шаг: Включает современный стандарт шифрования WPA2 для защиты беспроводного трафика от перехвата. Шаг 5. Настройка сервера аутентификации (RADIUS / AAA) Где искать: В том же окне безопасности перейдите на подвкладку AAA Servers. Что нужно указать: В разделе Authentication Servers выберите из списка IP-адрес заранее настроенного RADIUS-сервера (например, сервера авторизации пользователей). (Опционально) Укажите сервер аккаунтинга (Accounting Server), если требуется вести учет сессий. Что делает этот шаг: Перенаправляет запросы на ввод логина и пароля сотрудников на защищенный корпоративный сервер, вместо использования общего пароля для всех (как в WPA2 Personal). Шаг 6. Активация WLAN (Status) Что нужно сделать: В самом верху страницы настроек найдите пункт Status (Статус) и установите галочку Enabled (Включено). Затем нажмите кнопку Apply в правом верхнем углу для сохранения изменений. Что делает этот шаг: Запускает работу новой беспроводной сети в эфире точек доступа, делая её доступной для подключения корпоративных клиентов.
