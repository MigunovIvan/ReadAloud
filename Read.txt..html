11.1.2 Смягчение последствий атак на таблицу MAC-адресов (Mitigate MAC Address Table Attacks) В чем суть угрозы? Коммутаторы хранят в памяти таблицу MAC-адресов, чтобы знать, какому порту передавать трафик. По умолчанию эта таблица имеет ограниченный размер. Существуют атаки, при которых злоумышленник засыпает коммутатор тысячами поддельных MAC-адресов. В результате легитимные записи вытесняются, таблица переполняется, и коммутатор начинает работать как обычный неуправляемый хаб — рассылать весь входящий трафик на все порты подряд, позволяя злоумышленнику перехватывать чужие данные. Как работает защита (Port Security)? Самый простой и эффективный метод предотвращения таких атак — включение функции безопасности портов (Port Security). Функция ограничивает количество допустимых MAC-адресов на конкретном порту. Администратор может либо вручную прописать разрешенные MAC-адреса, либо разрешить коммутатору автоматически изучить ограниченное число адресов. Когда порт получает кадр, его исходный MAC-адрес сравнивается с разрешенным списком. Если устройство неавторизовано, коммутатор блокирует его трафик. 11.1.3 Включение безопасности портов (Enable Port Security) Важное правило настройки Команда включения безопасности портов (switchport port-security) может выдавать ошибку отказа (Command rejected), если порт находится в режиме динамического согласования (dynamic auto или dynamic desirable). Прежде чем активировать защиту, порт обязательно нужно перевести в статический режим доступа: Перейдите на интерфейс: interface fastethernet 0/1 Задайте режим доступа: switchport mode access Включите защиту: switchport port-security Проверка параметров порта Для просмотра текущих настроек безопасности используется команда: show port-security interface f0/1 В выводе команды вы увидите: Port Status: статус порта (например, Secure-down, если устройство не подключено, или Secure-up, если подключено). Violation Mode: режим нарушения (по умолчанию установлен Shutdown). Maximum MAC Addresses: максимальное число разрешенных адресов (по умолчанию равно 1). 11.1.4 Ограничение и изучение MAC-адресов (Limit and Learn MAC Addresses) Настройка лимита Чтобы задать максимальное количество устройств, которые могут подключиться к порту, используется команда: switchport port-security maximum [значение] (по умолчанию 1, максимум зависит от модели коммутатора). Три способа добавления MAC-адресов: Вручную (Manually Configured): Администратор сам прописывает статический адрес командой switchport port-security mac-address [mac]. Динамически (Dynamically Learned): Коммутатор автоматически запоминает подключенное устройство, но при перезагрузке эти данные стираются. Липкие MAC-адреса (Sticky): Самый удобный способ. Коммутатор автоматически изучает MAC-адрес подключенного устройства и «приклеивает» его к текущей конфигурации (switchport port-security mac-address sticky). Если сохранить конфигурацию, эти адреса запишутся в постоянную память (NVRAM). Для проверки всех изученных защищенных адресов используется команда: show port-security address 11.1.5 Старение безопасности портов (Port Security Aging) Зачем нужно старение? Функция старения позволяет автоматически удалять безопасные MAC-адреса по истечении времени без необходимости делать это вручную. Поддерживается два типа старения: Absolute (Абсолютное): Адреса удаляются ровно по истечении заданного времени, независимо от активности. Inactivity (По неактивности): Адреса удаляются только в том случае, если от них не поступало никакого трафика в течение заданного интервала. Как настроить: Задать время старения (в минутах от 0 до 1440): switchport port-security aging time 10 Выбрать тип старения: switchport port-security aging type inactivity 11.1.6 Режимы нарушения безопасности (Port Security Violation Modes) Если к защищенному порту подключается устройство с «чужим» MAC-адресом, происходит нарушение безопасности. Поведение коммутатора зависит от выбранного режима нарушения: switchport port-security violation [protect | restrict | shutdown] Shutdown (по умолчанию): Порт мгновенно переводится в защитное состояние отключения (error-disabled), гаснет индикатор (LED), отправляется системное сообщение (syslog), а счетчик нарушений увеличивается на 1. Restrict: Порт продолжает работать, но отбрасывает кадры с неизвестными MAC-адресами. При этом генерируется syslog-сообщение и увеличивается счетчик нарушений. Protect: Самый мягкий (и наименее информативный) режим. Неизвестный трафик просто отбрасывается, но syslog-сообщения не отправляются, а счетчик нарушений не растет. 11.1.7 Порты в состоянии Error-Disabled Что происходит при срабатывании режима Shutdown? Если порт перешел в состояние ошибки (err-disabled), он физически отключается — через него не передается никакой трафик, а порт отображается как неработающий. В статусе интерфейса будет указано err-disabled. Как вернуть порт к жизни? Просто так кабель переподключать бесполезно. Администратор должен устранить угрозу (отключить несанкционированное устройство), а затем вручную перезапустить порт на коммутаторе двумя командами: shutdown (перевести порт в принудительное выключение) no shutdown (вернуть порт в рабочее состояние) 11.1.8 Проверка безопасности портов (Verify Port Security) Для контроля корректности настроек используются четыре ключевые команды: show port-security — выводит общую сводку по всем защищенным портам на коммутаторе. show port-security interface [интерфейс] — показывает детальные параметры безопасности для конкретного порта. show run interface [интерфейс] — позволяет проверить, сохранились ли «липкие» MAC-адреса (sticky) в активной конфигурации. show port-security address — отображает таблицу всех изученных или прописанных вручную безопасных MAC-адресов с указанием VLAN и портов.
