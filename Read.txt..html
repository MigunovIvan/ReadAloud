Тема 5.3.1. Аргументы (Arguments) В структуре командной строки аргументы используются для указания объекта, с которым должна работать команда. Общий синтаксис выглядит так: command [options] [arguments]. Если передать команде ls имя конкретного каталога в качестве аргумента, она выведет содержимое именно этой папки, а не текущего рабочего каталога. Пример с одним аргументом: Команда ls /etc/ppp выведет список файлов, находящихся внутри системной папки /etc/ppp:ip-down.d ip-up.d Пример с несколькими аргументами: Команда ls поддерживает работу сразу с несколькими объектами. Если передать ей два пути ls /etc/ppp /etc/ssh, утилита последовательно отобразит содержимое каждого указанного каталога, сгруппировав вывод по отдельным блокам для каждой папки.
