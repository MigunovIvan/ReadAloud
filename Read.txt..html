Подраздел 8.3.1: Копирование нескольких файлов. Команда си-пи, которая пишется как cp, также позволяет копировать несколько файлов за один раз. Для этого в качестве места назначения необходимо указать каталог. Если указать несколько исходных файлов, а местом назначения выбрать обычный файл, команда завершится с ошибкой. В следующем примере сначала с помощью команды тач, которая пишется как touch, создаются три пустых файла в домашнем каталоге: file1, file2 и file3. Затем создается каталог с именем dir1 с помощью команды мкдир, которая пишется как mkdir. В приглашении командной строки sysadmin собака localhost двоеточие тильда знак доллара вводится команда: touch пробел file1 пробел file2 пробел file3. Затем вводится команда: mkdir пробел dir1. Теперь эти три файла можно скопировать в каталог dir1 за одну команду. В качестве аргументов сначала перечисляются исходные файлы, а последним аргументом указывается каталог назначения. В приглашении командной строки sysadmin собака localhost двоеточие тильда знак доллара вводится команда: cp пробел file1 пробел file2 пробел file3 пробел dir1. После выполнения этой команды файлы file1, file2 и file3 останутся в текущем каталоге, а их копии появятся внутри каталога dir1.
