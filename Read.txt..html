5.4.1 Обзор модуля: Концепции связующего дерева (STP Concepts) Данный материал подводит итог пятому модулю, который посвящен предотвращению петель в сетях второго уровня (Layer 2) с помощью протокола STP (Spanning Tree Protocol). Весь материал делится на три ключевых раздела. 1. Назначение STP (Purpose of STP) Проблема петель: В коммутируемых Ethernet-сетях избыточные физические пути создают логические петли второго уровня. Последствия петель: В отличие от протоколов третьего уровня (IPv4 и IPv6), у Ethernet нет встроенного механизма для удаления бесконечно циркулирующих кадров. Это приводит к нестабильности таблицы MAC-адресов, перегрузке каналов связи, высокой нагрузке на ЦП устройств и полному выходу сети из строя. Шторм широковещания (Broadcast Storm): Аномально высокий объем трафика, который способен за секунды парализовать работу всей сети. Решение — STP: Это сетевой протокол предотвращения петель, создающий топологию без петель при сохранении избыточности. Алгоритм связующего дерева (STA), изобретенный Радией Перлман, выбирает единственный корневой мост (Root Bridge), относительно которого все остальные коммутаторы определяют оптимальный путь с наименьшей стоимостью. 2. Операции STP (STP Operations) Процесс построения топологии без петель с помощью алгоритма STA состоит из четырех основных этапов: Выборы корневого моста (Root Bridge): Коммутаторы обмениваются служебными сообщениями BPDU (Bridge Protocol Data Unit), которые содержат идентификатор BID (Bridge ID). BID состоит из приоритета коммутатора (по умолчанию 32768), MAC-адреса и расширенного идентификатора системы. Коммутатор с наименьшим BID становится корневым. Если приоритеты равны, решающим фактором становится наименьший MAC-адрес. Выборы корневых портов (Root Ports): Каждый не-корневой коммутатор выбирает порт с наименьшей суммарной стоимостью пути до корневого моста (Internal Root Path Cost). Выборы назначенных портов (Designated Ports): Для каждого сегмента сети выбирается порт, имеющий наилучшую стоимость пути к корню. Выборы альтернативных/блокирующих портов (Alternate/Blocked Ports): Порты, которые не являются корневыми или назначенными, переводятся в состояние блокировки (discarding), что физически разрывает петлю. Дополнительные параметры: Для выбора порта при равной стоимости учитываются: наименьший BID отправителя, наименьший приоритет порта отправителя и наименьший ID порта отправителя. Сходимость STP зависит от трех таймеров: Hello, Forward Delay и Max Age. Состояния портов: блокировка (blocking), прослушивание (listening), обучение (learning), пересылка (forwarding) и отключено (disabled). В версиях PVST корневой мост выбирается индивидуально для каждого экземпляра VLAN. 3. Эволюция STP (Evolution of STP) С течением времени стандарт развивался для повышения производительности и скорости работы: RSTP (Rapid Spanning Tree Protocol): Улучшенная версия STP с более быстрой сходимостью. Использует состояния портов: learning, forwarding и discarding. PVST+ (Per-VLAN Spanning Tree Plus): Фирменная технология Cisco, создающая отдельный экземпляр связующего дерева для каждой VLAN. Поддерживает технологии защит и оптимизаций, такие как PortFast, BPDU guard, Root guard и Loop guard. На коммутаторах Cisco с IOS 15.0 и выше PVST+ включен по умолчанию. Rapid PVST+: Объединяет преимущества RSTP и PVST+, обеспечивая отдельный экземпляр 802.1w для каждой VLAN. PortFast: Функция, мгновенно переводящая порт доступа из состояния блокировки в режим пересылки (forwarding), минуя фазы прослушивания и обучения. Применяется к портам подключения конечных устройств (например, клиентов DHCP), чтобы они не ждали 30 секунд сходимости STP. BPDU guard: Функция безопасности Cisco, переводящая порт в защитное состояние err-disabled при попытке получить входящий пакет BPDU, защищая сеть от случайных петель. Переход к Layer 3: В современных крупных иерархических сетях сотен коммутаторов маршрутизация третьего уровня позволяет использовать избыточные пути без блокировки портов, поэтому во многих структурах STP оставляют только на уровне доступа (access layer).
