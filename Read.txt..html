Внешние команды Внешние команды — это отдельные бинарные исполняемые файлы, которые хранятся в различных каталогах файловой системы и запускаются оболочкой (shell). Когда вы вводите команду (например, ls), оболочка не ищет её наугад. Она последовательно просматривает директории, указанные в специальной системной переменной окружения PATH, в поисках исполняемого файла с именем ls. Как узнать расположение команды Перебирать вручную все каталоги из переменной PATH слишком долго и неудобно. Для этого существуют специальные встроенные инструменты: Команда which Она выполняет поиск по каталогам из переменной PATH и выводит полный путь к исполняемому файлу нужной команды. Пример: Ввод: which ls Результат: /bin/ls Ввод: which cal Результат: /usr/bin/cal Прямой вызов по абсолютному пути Внешнюю команду можно запустить напрямую, указав её полный путь в системе, не полагаясь на переменную PATH. Пример: /bin/ls выдаст тот же список файлов текущей директории, что и простая команда ls. Команда type Для внешних команд type показывает путь к исполняемому файлу точно так же, как и which. Пример: type cal выведет: cal is /usr/bin/cal. Разница между внешними командами и встроенными (Shell Builtins) Иногда результаты работы команд type и which для одной и той же команды могут отличаться. Например, для команды echo: type echo сообщает: echo is a shell builtin (это встроенная команда самой оболочки). which echo выводит: /bin/echo (показывает, что в системе также существует отдельный внешний бинарный файл echo). Чтобы увидеть все доступные варианты расположения команды (и встроенную версию, и внешние исполняемые файлы), используется ключ -a с командой type: Ввод: type -a echo Результат покажет все источники: сначала оболочка использует встроенную команду, но в системе также присутствует внешний файл /bin/echo.
