3.2.2.5 Обмен файлами и сетевые службы Совместный доступ к файлам Samba: Главный инструмент для интеграции с Windows. Позволяет компьютеру с Linux выглядеть и работать как обычный сервер Windows, обмениваться файлами и участвовать в общем сетевом домене. Netatalk: Проект, который превращает компьютер под управлением Linux в полноценный файловый сервер для компьютеров Apple Macintosh. Network File System или NFS: Родной сетевой протокол для операционных систем UNIX и Linux. Он интегрирован прямо в ядро системы, благодаря чему удаленную папку можно подключить как обычный локальный диск, делая работу с файлами полностью прозрачной для других программ. Сетевые службы и каталоги Доменная система имен или DNS: Превращает привычные нам доменные имена в уникальные числовые IP-адреса устройств в сети. Организации создают собственные серверы DNS, чтобы публиковать имена в интернете и управлять внутренними службами. Самый популярный сервер для этого называется bind. Служба каталогов LDAP: Используется для поиска и хранения информации об учетных записях пользователей и ролях безопасности. Объекты хранятся в виде иерархического дерева, что позволяет быстро находить сотрудников по отделам. Главная программа для реализации этой службы в Linux называется OpenLDAP. Динамическая настройка узлов или DHCP: Когда компьютер загружается, ему необходим IP-адрес для работы в локальной сети. Служба DHCP автоматически отслеживает запросы и выделяет свободный адрес из пула. Самым популярным сервером с открытым исходным кодом для этой задачи является ISC DHCP.
