Тема 13.3.9: Настройка области DHCP (Configure a DHCP Scope) В этой теме рассматривается процесс настройки пула динамических IP-адресов (DHCP Scope) для только что созданного интерфейса. Это необходимо, чтобы беспроводные клиенты при подключении к новой сети автоматически получали IP-адрес, маску подсети, адрес шлюза и DNS. Для успешной настройки области DHCP выполните следующие шаги: Шаг 1. Переход к настройкам DHCP на контроллере Где искать в меню: В верхнем меню графического интерфейса WLC перейдите на вкладку CONTROLLER (Контроллер), а затем в левом боковом меню выберите пункт DHCP и подпункт Internal DHCP Server (или перейдите в раздел Addresses, если используется встроенный сервер WLC). Что делает этот шаг: Открывает панель управления встроенным DHCP-сервером контроллера, где создаются пулы адресов для различных VLAN. Шаг 2. Создание нового DHCP-пула (Scope) Что нужно сделать: Нажмите кнопку New... (Создать новый) в правом верхнем углу. Что нужно указать: Введите имя пула (Scope Name), которое соответствует вашей сети или созданному ранее интерфейсу (например, VLAN5-Pool). Что делает этот шаг: Создает контейнер для группы IP-адресов, которые будут выдаваться клиентам определенной беспроводной сети. Шаг 3. Настройка диапазона выдаваемых IP-адресов Что нужно указать: Pool Start IP Address (Начальный IP-адрес диапазона) — например, 192.168.5.10. Pool End IP Address (Конечный IP-адрес диапазона) — например, 192.168.5.240. Что делает этот шаг: Определяет рамки, в пределах которых DHCP-сервер будет автоматически распределять свободные IP-адреса подключающимся устройствам. Шаг 4. Настройка сетевых параметров (Маска и Шлюз) Что нужно указать: Network Mask (Маска подсети) — например, 255.255.255.0. Default Router (Основной шлюз) — IP-адрес маршрутизатора или самого интерфейса контроллера, через который пойдет трафик наружу (в нашем примере: 192.168.5.254). Что делает этот шаг: Сообщает клиентам сетевую маску их подсети и адрес шлюза по умолчанию, без которого устройства не смогут выйти за пределы своей локальной сети (например, в интернет). Шаг 5. Настройка DNS-сервера Что нужно указать: В поле DNS Server введите IP-адрес DNS-сервера (например, публичный DNS Google 8.8.8.8 или корпоративный DNS-сервер сети). Что делает этот шаг: Позволяет клиентским устройствам преобразовывать доменные имена сайтов (например, cisco.com) в IP-адреса для корректного доступа в интернет. Шаг 6. Сохранение и проверка (Apply and Save) Что нужно сделать: Нажмите кнопку Apply (Применить) для сохранения пула, а затем не забудьте нажать Save Configuration в верхней части страницы, чтобы настройки не сбросились при перезагрузке устройства. Что делает этот шаг: Окончательно активирует DHCP-скоп, после чего подключенные к сети 5 устройства смогут успешно запрашивать и получать сетевые настройки.
