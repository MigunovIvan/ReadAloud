Тема 14.3: Обзор базовой конфигурации маршрутизатора 14.3.1 Топология (Topology) Перед тем как изучать таблицы маршрутизации, важно закрепить базовую настройку маршрутизатора на конкретной схеме сети. Описание топологии сети: Маршрутизаторы: В сети используются три маршрутизатора — R1, R2 и R3, соединенные с четырьмя коммутаторами S1, S2, S3 и S4. Подключения маршрутизатора R1: Маршрутизатор R1 подключается к коммутаторам S1 и S2 через гигабитные интерфейсы GigabitEthernet 0/0/0 и GigabitEthernet 0/0/1. К коммутатору S1 подключен компьютер PC1 в сети IPv4 10.0.1.0/24 и IPv6 2001:db8:acad:1::/64 с адресом оканчивающимся на .10 и ::10. К коммутатору S2 подключен компьютер PC2 в сети IPv4 10.0.2.0/24 и IPv6 2001:db8:acad:2::/64 с адресом .10 и ::10. Шлюзы по умолчанию на R1 для этих интерфейсов имеют адреса, оканчивающиеся на .1 и ::1. Межсетевые и последовательные соединения: Между маршрутизаторами R1 и R2 настроено последовательное (Serial) соединение точка-точка через порты Serial 0/1/0 и Serial 0/1/1 в сети IPv4 10.0.3.0/24 (в тексте также упоминается префикс /22) и IPv6 2001:db8:acad:3::/64. IP-адреса последовательного интерфейса R1 (Serial 0/1/1): .1 и ::1. IP-адреса последовательного интерфейса R2: .2 и ::2. Подключения маршрутизатора R2: Маршрутизатор R2 подключен к коммутаторам S3 и S4 через порты GigabitEthernet 0/0/0 и GigabitEthernet 0/0/1. Сеть коммутатора S3: IPv4 10.0.4.0/24 и IPv6 2001:db8:acad:4::/64. К нему подключен PC3 (.10 и ::10). Сеть коммутатора S4: IPv4 10.0.5.0/24 и IPv6 2001:db8:acad:5::/64. К нему подключен PC4 (.10 и ::10). Соединение R2 с провайдером (ISP) использует подсеть 209.165.200.224/30 и IPv6 2001:db8:feed:224::/64, где интерфейс R2 имеет адрес .225 (и ::1), а интерфейс провайдера — адрес .226 (и ::2). 14.3.2 Команды настройки (Configuration Commands) В данном разделе приведен полный пример настройки маршрутизатора R1 через интерфейс командной строки (CLI): Переход в режим настройки: Команда enable переводит в привилегированный режим (Router#). Команда configure terminal открывает глобальный режим конфигурации (Router(config)#). Базовые параметры безопасности и доступа: Установка имени хоста: hostname R1. Защита привилегированного режима: enable secret class. Настройка консольной линии связи: line console 0, включение синхронизации логов (logging synchronous), установка пароля (password cisco) и активация проверки входа (login). Настройка виртуальных линий удаленного доступа: line vty 0 4, установка пароля, включение входа и разрешение протоколов SSH и Telnet: transport input ssh telnet. Шифрование паролей: service password-encryption. Установка предупреждающего баннера: banner motd # с текстом предупреждения об ограничении несанкционированного доступа. Маршрутизация IPv6: Обязательная команда для включения маршрутизации IPv6 на устройстве: ipv6 unicast-routing. Настройка физических интерфейсов: Интерфейс GigabitEthernet 0/0/0 (связь с LAN 1): Описание: description Link to LAN 1 IPv4 адрес: ip address 10.0.1.1 255.255.255.0 IPv6 адреса: ipv6 address 2001:db8:acad:1::1/64 и локальный адрес связи ipv6 address fe80::1:a link-local Активация порта: no shutdown Интерфейс GigabitEthernet 0/0/1 (связь с LAN 2): Описание: description Link to LAN 2 IPv4 адрес: ip address 10.0.2.1 255.255.255.0 IPv6 адреса: ipv6 address 2001:db8:acad:2::1/64 и локальный ipv6 address fe80::1:b link-local Активация порта: no shutdown Интерфейс Serial 0/1/1 (связь с R2): Описание: description Link to R2 IPv4 адрес: ip address 10.0.3.1 255.255.255.0 IPv6 адреса: ipv6 address 2001:db8:acad:3::1/64 и локальный ipv6 address fe80::1:c link-local Активация порта: no shutdown Сохранение конфигурации: Команда copy running-config startup-config сохраняет текущую конфигурацию в энергонезависимую память. 14.3.3 Команды проверки (Verification Commands) Для контроля состояния оборудования и правильности настроек используются следующие основные команды (для IPv6 слово ip заменяется на ipv6): show ip interface brief — краткая сводка состояния интерфейсов и их IP-адресов. show running-config interface [тип номер] — просмотр конфигурации конкретного интерфейса. show interfaces — подробная статистика работы всех интерфейсов. show ip interface — детальные параметры IP для каждого интерфейса. show ip route — просмотр таблицы маршрутизации. ping — проверка сетевой связности с удаленными узлами. Пример вывода команды show ip interface brief для R1: GigabitEthernet0/0/0 — адрес 10.0.1.1, статус up/up (работает). GigabitEthernet0/0/1 — адрес 10.0.2.1, статус up/up (работает). Serial0/1/0 — адрес не назначен, статус administratively down / down (отключен администратором). Serial0/1/1 — адрес 10.0.3.1, статус up/up (работает). 14.3.4 Фильтрация вывода команд (Filter Command Output) Чтобы не просматривать длинные списки команд вручную, в командной строке Cisco применяется символ вертикальной черты (|), после которого указываются параметры фильтрации: section — выводит весь логический блок конфигурации, начинающийся с указанного слова (например, show running-config | section line vty). include — оставляет только те строки вывода, которые содержат заданное выражение (например, show ipv6 interface brief | include up). exclude — исключает из вывода строки, содержащие указанное выражение (например, скрытие неиспользуемых интерфейсов: show ip interface brief | exclude unassigned). begin — начинает вывод текста с первой строки, которая совпадает с заданным шаблоном (например, show ip route | begin Gateway). 14.3.5 Практическое задание Packet Tracer (Packet Tracer - Basic Router Configuration Review) Цель задания: Закрепить теорию на практике. Маршрутизаторы R1 и R2 имеют по две локальные сети. Поскольку R1 уже настроен, ваша задача — выполнить корректную настройку адресации для маршрутизатора R2 и проверить общую связанность между всеми локальными сетями с помощью скачиваемого файла Basic Router Configuration Review
