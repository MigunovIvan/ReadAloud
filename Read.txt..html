Тема 15.1.4: Команда настройки статического маршрута IPv6 Статические маршруты в протоколе IPv6 настраиваются с помощью глобальной конфигурационной команды ipv6 route. Полный синтаксис команды выглядит следующим образом: Router(config)# ipv6 route ipv6-prefix / prefix-length { ipv6-address | exit-intf [ ipv6-address ] } [ distance ] Большинство параметров этой команды абсолютно идентичны аналогичной команде для IPv4. Давайте разберем каждый параметр подробно: ipv6-prefix — определяет адрес сети назначения IPv6 для удаленной сети, который необходимо добавить в таблицу маршрутизации. /prefix-length — определяет длину префикса удаленной сети (маску подсети в формате IPv6). ipv6-address — указывает IP-адрес маршрутизатора следующего перехода (next-hop). Этот параметр обычно используется в сетях с широковещательной передачей, таких как Ethernet. Использование только IP-адреса может создать рекурсивный статический маршрут, при котором роутеру потребуется выполнить дополнительный поиск в таблице, чтобы определить выходной интерфейс. exit-intf — указывает локальный выходной интерфейс маршрутизатора, через который должны пересылаться пакеты. Такой подход создает напрямую подключенный статический маршрут (Directly connected static route). Обычно применяется в соединениях «точка-точка» (point-to-point). exit-intf ipv6-address — комбинация интерфейса и IP-адреса. Создает полностью определенный статический маршрут (Fully specified static route), так как в нем явно заданы и выходной интерфейс, и IP-адрес следующего перехода. distance — необязательный параметр, позволяющий назначить значение административного расстояния (Administrative Distance) в диапазоне от 1 до 255. Чаще всего используется для создания плавающего статического маршрута (Floating static route) путем установки значения, которое выше, чем у динамически изучаемых маршрутов. Важное техническое примечание: Чтобы маршрутизатор мог успешно пересылать IPv6-пакеты, на нем обязательно должна быть предварительно включена глобальная команда маршрутизации: ipv6 unicast-routing.
