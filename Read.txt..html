Подраздел 8.2.5: Вывод списка с использованием шаблонов глоббинга. Обычно для вывода списка файлов в каталоге используется команда ls, поэтому применение команды эхо, которая пишется как echo, могло показаться странным выбором. Однако у команды ls есть одна особенность, которая вызывает проблемы при выводе списков файлов с помощью шаблонов глоббинга. Помните, что именно командная оболочка, а не команда echo или команда ls, раскрывает шаблон глоббинга в соответствующие имена файлов. Другими словами, если выполняется команда echo пробел слэш etc слэш a звездочка, то оболочка еще до запуска команды echo заменяет a звездочка на все файлы и каталоги внутри каталога слэш etc, которые соответствуют этому шаблону. Таким образом, если запускается команда ls пробел слэш etc слэш a звездочка, то на самом деле оболочка выполнит следующую команду: ls пробел слэш etc слэш adduser точка conf пробел слэш etc слэш alternatives пробел слэш etc слэш apparmor пробел слэш etc слэш apparmor точка d пробел слэш etc слэш apt. Когда команда ls видит сразу несколько аргументов, она выполняет операцию вывода списка для каждого элемента по отдельности. Иными словами, ls пробел слэш etc слэш a звездочка — это то же самое, что последовательно выполнить следующие команды: ls пробел слэш etc слэш adduser точка conf ls пробел слэш etc слэш alternatives ls пробел слэш etc слэш apparmor ls пробел слэш etc слэш apparmor точка d ls пробел слэш etc слэш apt Теперь подумайте, что происходит, если команде ls передать файл, например слэш etc слэш adduser точка conf. В приглашении командной строки sysadmin собака localhost двоеточие тильда знак доллара вводится команда: ls пробел слэш etc слэш adduser точка conf. Система выведет: слэш etc слэш adduser точка conf. Запуск команды ls для одного файла приводит к выводу имени этого файла. Обычно это полезно, если используется опция минус l, чтобы увидеть подробные сведения о конкретном файле. В приглашении командной строки sysadmin собака localhost двоеточие тильда знак доллара вводится команда: ls пробел минус l пробел слэш etc слэш adduser точка conf. Система выведет: дефис rw дефис r дефис дефис r дефис дефис пробел 1 пробел root пробел root пробел 3028 пробел May пробел 26 пробел 2018 пробел слэш etc слэш adduser точка conf. Однако что будет, если в качестве аргумента команде ls передать имя каталога? В этом случае вывод команды отличается от ситуации, когда аргументом был обычный файл. В приглашении командной строки sysadmin собака localhost двоеточие тильда знак доллара вводится команда: ls пробел слэш etc слэш apparmor. Система выведет: init пробел parser точка conf пробел subdomain точка conf. Если команде ls передать имя каталога, команда покажет содержимое этого каталога, то есть имена файлов внутри него, а не само имя каталога. Имена файлов из предыдущего примера — это имена файлов внутри каталога слэш etc слэш apparmor. Почему это становится проблемой при использовании шаблонов глоббинга? Рассмотрим следующий вывод. В приглашении командной строки sysadmin собака localhost двоеточие тильда знак доллара вводится команда: ls пробел слэш etc слэш ap звездочка. Система выведет для слэш etc слэш apparmor: init пробел parser точка conf пробел subdomain точка conf. Для слэш etc слэш apparmor точка d выведет: abstractions пробел disable пробел local пробел tunables пробел usr точка sbin точка named пробел cache пробел force дефис complain пробел sbin точка dhclient пробел usr точка bin точка man пробел usr точка sbin точка rsyslogd. Для слэш etc слэш apt выведет: apt точка conf точка d пробел preferences точка d пробел sources точка list пробел sources точка list точка d пробел trusted точка gpg точка d. Когда команда ls видит имя файла в качестве аргумента, она просто выводит имя файла. Но для любого каталога она выводит содержимое этого каталога, а не само имя каталога. Это становится еще более запутанным в ситуации, подобной следующей. В приглашении командной строки sysadmin собака localhost двоеточие тильда знак доллара вводится команда: ls пробел слэш etc слэш x звездочка. Система выведет: autostart пробел systemd пробел user дефис dirs точка conf пробел user дефис dirs точка defaults. В предыдущем примере может показаться, что команда ls работает просто неправильно. Однако на самом деле единственное, что подходит под шаблон слэш etc слэш x звездочка — это каталог слэш etc слэш xdg. Поэтому команда ls вывела только файлы, находящиеся внутри этого каталога. Для этой проблемы есть простое решение: всегда используйте опцию минус d вместе с шаблонами глоббинга. Она указывает команде ls выводить имена каталогов, а не их содержимое. В приглашении командной строки sysadmin собака localhost двоеточие тильда знак доллара вводится команда: ls пробел минус d пробел слэш etc слэш x звездочка. Система выведет: слэш etc слэш xdg
