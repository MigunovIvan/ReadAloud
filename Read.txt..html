Тема 12.7.5: Аутентификация домашнего пользователя (Authenticating a Home User) Выбор стандартов для домашних роутеров Обычные домашние маршрутизаторы чаще всего предлагают на выбор два основных стандарта аутентификации: WPA и WPA2. При этом стандарт WPA2 является более мощным, надежным и предпочтительным вариантом защиты. В настройках беспроводной сети для протокола WPA2 администратору предлагается выбрать один из двух режимов аутентификации: Personal (Личный / Персональный режим). Enterprise (Корпоративный режим). Давайте подробно разберем оба варианта, опираясь на интерфейс настройки маршрутизатора. 1. Режим WPA2 Personal (Home/Small Office) Назначение: Этот режим разработан специально для домашних сетей или небольших офисов (Small Office, Home Office — SOHO). Как происходит аутентификация: Пользователи подключаются к сети с помощью предварительно разделенного ключа (Pre-Shared Key, или сокращенно PSK). Беспроводные клиентские устройства проходят аутентификацию напрямую на беспроводном роутере, используя общий пароль. Главная особенность: Для работы этого режима не требуется никаких специальных серверов аутентификации. Все настройки выполняются локально на самом роутере. 2. WPA2 Enterprise (Enterprise Network) Назначение: Данный режим предназначен для крупных корпоративных сетей, где требования к безопасности значительно выше. Инфраструктура: Для его работы обязательно требуется наличие внешнего сервера аутентификации — RADIUS (Remote Authentication Dial-In User Service). Уровень сложности и безопасности: Настраивать такой режим сложнее, однако он обеспечивает беспрецедентно высокий уровень безопасности. Процесс подключения: Сначала само беспроводное устройство (точка доступа или роутер) должно успешно пройти взаимную аутентификацию на RADIUS-сервере. После этого каждый конкретный пользователь проходит индивидуальную аутентификацию по промышленному стандарту 802.1X, который для проверки учетных данных использует специальный протокол EAP (Extensible Authentication Protocol). Практический пример из интерфейса В окне конфигурации беспроводного роутера администратор может выбрать режим WPA2 Personal для диапазона 2.4 GHz, указав общий пароль для подключения устройств, либо переключиться на корпоративный режим с привязкой к IP-адресу RADIUS-сервера.
