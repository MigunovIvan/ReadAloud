8.4 Перемещение файлов. Чтобы переместить файл, используйте команду mv. Синтаксис команды mv во многом похож на команду cp: mv источник назначение. В следующем примере файл hosts, который был создан ранее, перемещается из текущего каталога в каталог Videos. Пользователь sysadmin на хосте localhost в домашнем каталоге тильда выполняет команду: ls. Система выводит содержимое текущего каталога: Desktop, Downloads, Pictures, Templates, example.txt, hosts.copy, Documents, Music, Public, Videos, hosts. Далее пользователь sysadmin выполняет команду: mv hosts Videos. Снова выполняется команда: ls. Теперь в списке есть Desktop, Downloads, Pictures, Templates, example.txt, Documents, Music, Public, Videos, hosts.copy. Файл hosts больше не отображается в текущем каталоге. Выполняется команда: ls Videos. Система выводит содержимое каталога Videos, и там находится файл hosts. Когда файл перемещается, он удаляется из исходного расположения и помещается в новое расположение. Перемещение файлов в Linux может быть связано с определенными нюансами, поскольку пользователям требуются специальные права доступа для удаления файлов из каталога. Без нужных прав возвращается сообщение об ошибке Permission denied, то есть в доступе отказано. В примере в терминале пользователь sysadmin в домашнем каталоге тильда пытается переместить системный файл из корневого каталога etc в текущий каталог с помощью точки: mv /etc/hosts точка. Система выводит сообщение об ошибке: mv: невозможно переместить /etc/hosts в ./hosts: в доступе отказано. Примечание: права доступа будут подробно рассмотрены далее в курсе.
