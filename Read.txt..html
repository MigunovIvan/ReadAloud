Архивирование файлов. Если вам нужно отправить кому-то несколько файлов, можно сжать каждый файл по отдельности. Тогда общий объём данных окажется меньше, чем при отправке несжатых файлов, однако вам всё равно придётся работать сразу с множеством отдельных файлов. Решением этой проблемы является архивирование. Традиционная утилита UNIX для архивирования файлов называется tar — это сокращение от словосочетания ленточный архив, по-английски Tape Archive. Исторически она использовалась для потоковой записи множества файлов на магнитную ленту при резервном копировании или передаче данных. Команда tar берёт несколько файлов и создаёт один общий выходной файл, который на другом конце передачи можно снова разделить на исходные файлы. У команды tar есть три основных режима работы, с которыми полезно хорошо разобраться: Создание — сделать новый архив из набора файлов. Извлечение — достать один или несколько файлов из архива. Список — показать содержимое архива без его извлечения. Понимание этих режимов — ключ к тому, чтобы правильно подбирать параметры командной строки для нужной задачи. Помимо самого режима, важно не забывать, где именно в команде указывается имя архива, поскольку в командной строке может перечисляться сразу несколько имён файлов.
