3.4.1 Команды настройки транка Теперь, когда вы настроили и проверили VLAN, пришло время настроить и проверить транки VLAN. Транк VLAN — это канал уровня 2 между двумя коммутаторами, по которому передается трафик для всех VLAN, если только список разрешенных VLAN не ограничен вручную или динамически. Для включения магистральных каналов связи настройте соединительные порты с помощью набора команд конфигурации интерфейса: Сначала перейдите в режим глобальной конфигурации командой: configure terminal. Затем войдите в режим настройки интерфейса командой: interface и укажите идентификатор интерфейса. Переведите порт в постоянный режим транкинга командой: switchport mode trunk. Установите для собственного VLAN значение, отличное от VLAN 1, командой: switchport trunk native vlan и номер VLAN. Укажите список VLAN, разрешенных на транковом канале связи, командой: switchport trunk allowed vlan и список VLAN. Вернитесь в привилегированный режим EXEC командой: end. 3.4.2 Пример конфигурации магистрали VLAN 10, 20 и 30 поддерживают компьютеры преподавателей, студентов и гостей. Порт FastEthernet 0/1 на коммутаторе S1 настроен как транковый порт и перенаправляет трафик для VLAN 10, 20 и 30. VLAN 99 настроен как собственный VLAN. С каждой виртуальной локальной сетью связаны следующие подсети: VLAN 10, Преподаватели и сотрудники: 172.17.10.0/24 VLAN 20, Студенты: 172.17.20.0/24 VLAN 30, Гости: 172.17.30.0/24 VLAN 99, Собственный: 172.17.99.0/24 Пример конфигурации порта FastEthernet 0/1 на коммутаторе S1 в качестве транкового порта, где собственная VLAN изменена на VLAN 99, а список разрешенных VLAN ограничен значениями 10, 20, 30 и 99: interface fastEthernet 0/1 switchport mode trunk switchport trunk native vlan 99 switchport trunk allowed vlan 10,20,30,99 end Примечание: Данная конфигурация предполагает использование коммутаторов Cisco Catalyst 2960, которые автоматически используют инкапсуляцию 802.1Q на транковых каналах. Для других коммутаторов может потребоваться ручная настройка инкапсуляции. Всегда настраивайте оба конца транкового канала с одной и той же собственной VLAN. Если конфигурация транкового канала 802.1Q не совпадает на обоих концах, программное обеспечение Cisco IOS сообщит об ошибках. 3.4.3 Проверка конфигурации транка Конфигурация проверяется с помощью команды: show interfaces идентификатор интерфейса switchport. Пример вывода команды show interfaces fa0/1 switchport: Name: Fa0/1 Switchport: Enabled Administrative Mode: trunk Operational Mode: trunk Administrative Trunking Encapsulation: dot1q Operational Trunking Encapsulation: dot1q Negotiation of Trunking: On Access Mode VLAN: 1 (default) Trunking Native Mode VLAN: 99 (VLAN0099) Voice VLAN: none Trunking VLANs Enabled: 10,20,30,99 Pruning VLANs Enabled: 2-1001 В выводе показано, что для порта Fa0/1 установлен административный режим trunk. Порт находится в режиме транкинга. Также подтверждается, что собственная VLAN — это VLAN 99, а на транковом порту включены VLAN 10, 20, 30 и 99. Примечание: Еще одна полезная команда для проверки транковых интерфейсов — команда show interface trunk. 3.4.4 Сброс транка в состояние по умолчанию Используйте команды no switchport trunk allowed vlan и no switchport trunk native vlan, чтобы удалить разрешенные VLAN и сбросить собственный VLAN транка. После сброса до состояния по умолчанию транк разрешает все VLAN и использует VLAN 1 в качестве собственного VLAN. Команды, используемые для сброса всех характеристик транкингового интерфейса до настроек по умолчанию: interface fa0/1 no switchport trunk allowed vlan no switchport trunk native vlan end Чтобы удалить функцию транка с порта и перевести его в статический режим доступа, используются команды: interface fa0/1 switchport mode access end
