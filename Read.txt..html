Несмотря на всю полезность классических страниц руководства (man pages), у них есть существенный недостаток. Каждая страница man представляет собой изолированный документ, который никак не связан с остальными. Даже если в разделе «Смотрите также» (SEE ALSO) могут упоминаться другие команды, в целом они остаются независимыми источниками информации. Для решения этой проблемы была создана система документации info и одноименная команда. Её главная цель — предложить пользователю единую логическую структуру, которая делает чтение и изучение документации намного проще и последовательнее. Вместо множества разрозненных файлов вся документация в формате info объединяется в единую «книга-сводку», охватывающую доступные команды и возможности. Внутри документов info информация разбита по категориям, что работает по принципу оглавления обычной книги. Для перехода между разделами и темами используются удобные гиперссылки. Еще одно важное преимущество документации info перед man-страницами заключается в стиле изложения. Если man-страницы созданы в первую очередь как справочный ресурс для быстрого поиска параметров, то документы info написаны скорее как обучающее руководство, что делает их идеальными для последовательного изучения новой темы.
