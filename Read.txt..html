15.1.1. Виды статических маршрутов Введение в статическую маршрутизацию Статические маршруты широко применяются в реальных компьютерных сетях. Это утверждение остается верным даже в тех случаях, когда на оборудовании уже настроен какой-либо динамический протокол маршрутизации. Классический пример из практики: организация может настроить дефолтный (маршрут по умолчанию) статический маршрут в сторону провайдера интернет-услуг, а затем распространять этот маршрут на остальные корпоративные маршрутизаторы с помощью динамического протокола. Поддерживаемые типы статических маршрутов Статические маршруты можно конфигурировать как для сетевого протокола четвертой версии (IPv4), так и для шестой версии (IPv6). Оба этих протокола поддерживают следующие четыре основные разновидности статических маршрутов: Стандартный статический маршрут (Standard static route): Это базовый маршрут, вручную указывающий путь к конкретной удаленной сети. Маршрут по умолчанию (Default static route): Специальный маршрут, который перенаправляет весь трафик, для которого у маршрутизатора нет точных записей в таблице. Чаще всего используется для выхода в интернет. Плавающий статический маршрут (Floating static route): Резервный маршрут, который активируется автоматически только в том случае, если падает основной (динамический или статический) канал связи. Суммарный статический маршрут (Summary static route): Маршрут, объединяющий сразу несколько подсетей в одну запись, что позволяет существенно уменьшить размер таблицы маршрутизации. Команды глобальной конфигурации Для непосредственного создания статических маршрутов на оборудовании Cisco используются специальные глобальные команды: Для IPv4 применяется команда ip route. Для IPv6 применяется команда ipv6 route.
