Тема 12.7.7: Аутентификация в корпоративных сетях (Authentication in the Enterprise) Введение В беспроводных сетях с повышенными требованиями к безопасности стандартного пароля недостаточно. Для предоставления доступа беспроводным клиентам требуется дополнительный уровень аутентификации и входа. Такой режим безопасности называется Enterprise и требует использования специального сервера — AAA RADIUS (Authentication, Authorization, and Accounting). 1. Ключевые компоненты настройки RADIUS-сервера В панели администратора беспроводного маршрутизатора для режима Enterprise настраиваются следующие параметры: RADIUS Server IP address (IP-адрес RADIUS-сервера): Указывается доступный в сети IP-адрес, по которому маршрутизатор может связаться с сервером аутентификации. UDP port numbers (Номера UDP-портов): Официально зарезервированные порты: порт 1812 используется для аутентификации (RADIUS Authentication), а порт 1813 — для учета сессий (RADIUS Accounting). Однако на практике система также может использовать альтернативные порты 1645 и 1646. Shared key (Общий ключ / пароль): Это надежный пароль, который используется исключительно для взаимной аутентификации между точкой доступа (или беспроводным маршрутизатором) и сервером RADIUS. Важная деталь: Общий ключ не нужно настраивать на устройствах обычных пользователей (клиентов). Он требуется только на точке доступа для установления доверительного соединения с сервером. 2. Как работает процесс проверки пользователей Аутентификация и авторизация конечных пользователей выполняются централизованно с помощью стандарта 802.1X. Процесс входа по стандарту 802.1X использует структуру EAP (Extensible Authentication Protocol) для обмена данными между беспроводным клиентом, точкой доступа и сервером RADIUS. Что делает EAP: EAP обеспечивает безопасный механизм аутентификации, а также позволяет согласовать надежный персональный ключ шифрования, который затем применяется для защиты сеанса связи с использованием шифрования TKIP или AES.
