Модуль 15: Статическая маршрутизация Тема 15.2.2: IPv6 Next-Hop Static Route 1. Основные отличия IPv6 от IPv4 В теме 15.2.2 рассматривается настройка точно такого же статического маршрута через «следующий переход» (next-hop), но уже для протокола IPv6. Главные отличия от IPv4: Обязательная глобальная команда: Прежде чем роутер Cisco начнет обрабатывать и маршрутизировать трафик IPv6, на нем в обязательном порядке нужно включить глобальную маршрутизацию с помощью команды ipv6 unicast-routing. Без этой команды роутер не принимает пакеты IPv6 к пересылке. Формат адресов: Вместо коротких четырех октетов IPv4 используются длинные 128-битные шестнадцатеричные адреса IPv6 (например, 2001:db8:acad:1::/64). 2. Топология и задача Топология сети остается ровно такой же, как и в предыдущем уроке (три роутера: R1, R2, R3). Роутеру R1 нужно прописать статические маршруты, чтобы он знал, как отправлять данные в три удаленные сети IPv6, к которым он не подключен напрямую: Локальная сеть роутера R2: 2001:db8:acad:1::/64 Канал связи между R2 и R3: 2001:db8:cafe:1::/64 Локальная сеть роутера R3: 2001:db8:cafe:2::/64 В качестве адреса следующего перехода (next-hop) для всех трех маршрутов выступает глобальный IPv6-адрес соседнего маршрутизатора R2 на канале связи: 2001:db8:acad:2::2. 3. Команды настройки на роутере R1 (CLI) Чтобы настроить маршрутизацию, администратор вводит следующие команды в режиме глобальной конфигурации: Включение поддержки IPv6-маршрутизации:R1(config)# ipv6 unicast-routing Маршрут до локальной сети R2:R1(config)# ipv6 route 2001:db8:acad:1::/64 2001:db8:acad:2::2 Маршрут до промежуточного канала связи между R2 и R3:R1(config)# ipv6 route 2001:db8:acad:cafe:1::/64 2001:db8:acad:2::2 (В курсе указано: 2001:db8:cafe:1::/64 2001:db8:acad:2::2) Маршрут до удаленной локальной сети R3:R1(config)# ipv6 route 2001:db8:cafe:2::/64 2001:db8:acad:2::2 4. Проверка таблицы маршрутизации IPv6 Для проверки корректности настройки используется команда show ipv6 route. В выхлопе команды отобразится таблица маршрутизации IPv6, где добавленные нами записи будут помечены буквой S (Static): S 2001:DB8:ACAD:1::/64 [1/0] via 2001:DB8:ACAD:2::2 S 2001:DB8:CAFE:1::/64 [1/0] via 2001:DB8:ACAD:2::2 S 2001:DB8:CAFE:2::/64 [1/0] via 2001:DB8:ACAD:2::2 Что важно запомнить из вывода: Буква S означает статический маршрут. Значение [1/0] показывает административное расстояние (1) и метрику. Конструкция via 2001:DB8:ACAD:2::2 указывает IP-адрес шлюза (следующего роутера R2), на который R1 будет пересылать пакеты для указанных сетей.
