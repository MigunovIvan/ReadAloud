Глава 7. Навигация по файловой системе. Раздел 7.1. Введение. В операционной системе Linux абсолютно всё рассматривается как файл. Обычные файлы используются для хранения различных данных, таких как текст, графика или программы. Каталоги — это особый тип файлов, который нужен для хранения других файлов. Пользователи операционных систем Windows и Mac OS X обычно называют каталоги папками. В любом случае каталоги служат для создания иерархической структуры организации данных, то есть системы с четкой вложенностью. При этом сама структура каталогов может немного отличаться в зависимости от того, какой именно тип системы используется. При работе в операционной системе Linux очень важно уметь управлять файлами и каталогами. В некоторых дистрибутивах Linux есть программы с графическим интерфейсом, которые позволяют удобно работать с файлами. Однако гораздо полезнее и эффективнее уметь выполнять все эти операции через командную строку.
